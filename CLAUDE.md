## Project Overview

ICIDD 2025 (創新數位設計國際研討會) — a static multi-page symposium website built with plain HTML, Tailwind CSS v3, and vanilla JavaScript. No bundler or framework is involved.

## Development Commands

```bash
# Install dev dependencies (Tailwind + PostCSS)
npm install

# Compile Tailwind CSS (watch mode — required during development)
npm run watch
# Equivalent: tailwindcss -i ./src/input.css -o ./src/output.css --watch
```

All pages link to `./output.css`, which is the compiled output. Always run the watch command while editing styles; `output.css` is committed to the repo and must be kept up to date.

To preview, open any HTML file in `src/` directly in a browser, or use VS Code Live Server pointing at `src/`.

## Architecture

### File layout

- `src/*.html` — all pages; each is self-contained with its own `<head>` and a copy of the nav/footer
- `src/input.css` — Tailwind source (custom component classes defined here with `@apply`)
- `src/output.css` — compiled CSS (committed; generated by the watch command)
- `src/app.js` — single shared JS file included by every page; handles mobile menu, sticky nav, and submenu toggling
- `img/` — all image assets (banners, logos, speaker photos, etc.)

### Design tokens (tailwind.config.js)

Custom colors used throughout:
- `main` → `#E4007F` (primary pink/magenta, headings and accents)
- `stress` → `#C6006F` (hover state for main)
- `content` → `#cdd0d8` (body text)
- `listbg` / `downmenubg` → `#252632` (card and dropdown backgrounds)
- Background: `#161823` (set globally in `input.css`)

Custom breakpoints: `sm: 480px`, `md: 768px`, `lg: 976px`, `xl: 1440px`

Font: Noto Sans TC (loaded from Google Fonts in each HTML file's `<head>`)

### Navigation pattern

Every page includes two nav bars:
1. `#main-menu` — visible at the top of the page
2. `#sticky-menu` — hidden by default, revealed via `IntersectionObserver` in `app.js` when `#main-menu` scrolls out of view

The mobile menu (`.mobile-menu`) is toggled by `.mobile-menu-button` elements and repositioned on scroll via a `window.scroll` listener in `app.js`.

### Pages

- `index.html` — homepage with hero banner and countdown timer
- `about.html` — conference overview
- `agenda.html`, `agenda_A–F.html` — session schedule pages
- `speakers01–03.html` — speaker listing pages
- `organizing.html` — organizing committee
- `submission.html` — paper submission info
- `404.html` — custom error page

## Collaboration Principles

1. **逐步思考**：回答前先展示思考過程，不直接跳到結論。
2. **釐清需求**：若需求不夠清楚，主動要求補充說明，再開始作業。
3. **一問一答**：遇到需要多方確認的問題時，每次只問一個問題，等待回覆後再繼續。
4. **誠實回覆**：不知道的事直接說不知道，不捏造或推測不確定的資訊。
